# 黎明界决策系统 · Windows 使用说明

> **本项目是决策系统，仅提供决策，不是一键化自动工具。**
> 本系统接收客户端状态并返回建议，不负责登录、点击或执行游戏操作。

## 首次启动

1. 解压整个压缩包，保留同目录的 DLL、`config`、`data` 和 `models`。
2. 双击 `黎明界决策系统.exe`，等顶部显示「服务在线」，确认总开关已打开。使用兼容协议的客户端时，监听地址和端口保持为 `127.0.0.1:8081`。
3. 启动雷电模拟器或 MuMu 模拟器，按下文建立 ADB 转发。
4. 进入游戏的黎明界，触发一次需要决策的操作，在控制台左侧「决策日志」查看请求和结果。各项策略可在左侧配置页修改，修改后点「保存配置」。

GUI 打开后会启动决策服务。`labyrinth_server.exe` 供只用命令行的场景使用。两者使用同一端口时只运行一个。

## 建立 ADB 转发

启动模拟器并开启 ADB 调试，然后在发布目录双击 `adb_reverse.cmd`。脚本会优先使用随包附带的 `adb.exe`，两个配套 DLL 也在同一目录。

- 只有一台 ADB 设备处于 `device` 状态时，脚本会自动选中它。
- 有多台时，窗口会显示编号、设备串号和可用的设备信息。输入编号后按回车。直接按回车可以取消。
- 列表为空时，检查模拟器是否开启 ADB 调试。部分模拟器需要先按界面显示的本机地址和端口执行 `adb connect`。 [雷电模拟器 ADB 指南](https://help.ldmnq.com/docs/lei-dian-mo-ni-qi-ADB-ming-ling-shi-yong-shuo-ming/lie-yan-jue-xing-yi-jian-ri-chang-ling-ke)

脚本把选中的模拟器内 `127.0.0.1:8081` 转发到 Windows 的 `127.0.0.1:8081`。成功、失败或取消后，窗口都会停留，按任意键退出。关闭窗口后，已建立的映射仍由 ADB 保持。多开时可再运行一次，为其他实例各建立一条映射。模拟器重启后，若映射消失，再运行脚本。
